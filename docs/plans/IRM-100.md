# IRM-100: Keep personal data out of app logs

App logs never contain a personal identity number, a name, a session token or a full IP address; a Vitest test through the fake BankID checks it, and `docs/privacy/records.md` says so. Server log retention is IRM-115's.

## Progress

- Test added to `src/server/login.server.test.ts`; it fails when `pollLogin` logs the cookie header and passes otherwise (`npx vitest run src/server/login.server.test.ts`).
- `docs/privacy/records.md` log row updated.

## Decisions

- The app has only two log sites (startup mode line, sweep errors); none prints personal data, so no code change was needed.
