# IRM-235 Links inside the app reload the whole app

Plain `<a href>` and `location.assign` inside `/app` threw the app away. Use the router's `Link`, `navigate` and `history.push`; Logga ut keeps its full reload (owner decision 2026-10-26).

## Progress

- Links in konto, bekrafta-epost, 404/error screens, the Shell redirect and the login return now navigate client-side.
- `radera-konto` search param `raderat` is optional in the URL so the link stays clean.
- Proved by `make check` (e2e `the login return and in-app links never reload the document`; the existing Logga ut test covers the reload and the 401).

## Decisions

- Class of bug: a hard navigation inside a client-only shell. The Shell redirect has no direct no-reload test.
