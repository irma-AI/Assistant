## Decisions
- Tenant isolation machinery ships without touching existing tables: `users`, `sessions` and login run before an organisation is known, so RLS on `roles` and `memberships` waits for the restricted login.
- The role is NOLOGIN in the migration; enabling its login and password is a deployment step, so no secret is in the repository.
