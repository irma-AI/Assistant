# Unsubscribe test fails 1 run in 16: the tampered signature can equal the real one

The test tampers with the unsubscribe link with `link.replace(/sig=./, 'sig=0')`. When the real signature already starts with `0`, the link is unchanged and returns 200 instead of 400 (about 1 run in 16). Fix: change the first character to one that differs from the real one; keep the file under the 300-line `max-lines` limit.
