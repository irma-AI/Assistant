# IRM-239: Guard: a new migration must sort after every migration on the base branch

See the Linear issue for the description. Criteria are in IRM-239.criteria.json.

## Progress

- `guards/migration-order.test.sh` passes six cases (unchanged, higher, lower, equal to base max, two added sharing a number, two higher); `make check-repo` passes. The CI wiring is `make check-repo` in `ci`, which runs on `pull_request` and `merge_group` with full history. `make check-app` needs a database and was not run here.

## Decisions

- A shell guard run by `make check-repo` (so `ci` runs it on PRs and in the merge queue), comparing HEAD with `origin/main`. It is not a `.jq` policy guard, which only sees the PR's file list, not the base branch's migrations.
