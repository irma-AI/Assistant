# IRM-144: Customer register (kundregister)

See the Linear issue (description with the 2026-10-25 decisions).

## Progress
- Migration `0009_customers.sql` (RLS, FORCE, `assistant_app` grants), `customers.manage` permission, `/api/v1/orgs/:orgId/customers` (list, create, PUT, DELETE, import), screen `/app/org/$orgId/kunder`.
- Proof: `pnpm exec vitest run src/server/customers.server.test.ts`, `pnpm exec playwright test e2e/customers.spec.ts` (both iPhone projects).

## Decisions
- First tenant table: every query runs in `inOrganisation`; the RLS test uses `set local role assistant_app`.
- A hand-written CSV parser (`src/api/customers.ts`, shared with the screen) instead of a dependency; it throws on an unterminated quote.
- Not built: a unique organisation number per organisation (duplicates are allowed), Bolagsverket lookup (IRM-168), personnummer (ROT/RUT, Kivra issues).
- The screen is unstyled like the other `/app` screens; IRM-187 builds the look (as in IRM-126).
