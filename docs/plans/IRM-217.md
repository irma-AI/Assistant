# A cancelled smoke test leaves a deploy live with no rollback and no issue

`rollback` in `.github/workflows/release.yml` ran on `failure()`, which is false when `smoke` is cancelled or times out. Owner decision (2026-10-26): any smoke result short of success rolls back; use `always() && needs.deploy.result == 'success' && needs.smoke.result != 'success'`.

## Progress
- Condition changed; both criteria hold by that condition (`cancelled` and timed-out results are `!= 'success'`). Proved with `make check-repo`.

## Decisions
- Wider class: `failure()` in a job `if:` misses `cancelled` upstream results; use an explicit `needs.<job>.result` test.
